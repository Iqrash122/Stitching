# Installation and development

Requires PHP 8.4, Composer 2, Node.js 24/npm, and PostgreSQL 17. Docker provides these without host PHP or Node. Network access is needed for dependency/image downloads. Docker startup has not been executed in this environment.

## Docker

With Docker Desktop/Engine running, from the extracted project:

```sh
docker run --rm -v "${PWD}:/workspace" -w /workspace node:24-bookworm-slim node scripts/workspace/configure.mjs
docker compose up -d --build
docker compose exec workspace bash scripts/workspace/install.sh
docker compose exec workspace bash scripts/workspace/check.sh
docker compose exec workspace php artisan studio:owner your-email@example.com
docker compose exec workspace bash scripts/workspace/start.sh
```

Owner provisioning prompts for a private password, minimum 12 characters. Registration is disabled. If an owner already exists, skip provisioning. Use `studio:owner your-email@example.com --recover` to recover access through a trusted server terminal.

Open http://localhost:8000. Keep the final command running; it starts the web server, Vite, queue worker and scheduler. Stop containers with `docker compose stop`; volumes retain data. Never use `docker compose down -v` on data you need. On Linux set DEV_UID/DEV_GID in .env before building if your UID/GID differs from 1000.

Windows users can run `powershell -File scripts/workspace/start-windows.ps1` instead. If system policy blocks scripts, use the manual commands without changing security policy.

## Native setup

With the runtimes and PHP extensions installed:

```sh
cp .env.example .env
composer install
npm ci
php artisan key:generate
```

Configure DB_HOST, DB_PORT, DB_DATABASE, DB_USERNAME and DB_PASSWORD in .env for an empty PostgreSQL development database, then:

```sh
php artisan migrate
php artisan db:seed
php artisan studio:owner your-email@example.com
php artisan wayfinder:generate --with-form
npm run build
bash scripts/workspace/start.sh
```

Required extensions include PDO PostgreSQL, bcmath, intl, mbstring, XML/DOM, zip, fileinfo and GD. Keep .env private. Templates and payment methods are seeded idempotently; no default owner or product prices are created.

## Checks

```sh
npm run types:check
npm run check
npm run build
php artisan test
php artisan test --configuration=phpunit.pgsql.xml
```

Default feature tests reset an in-memory SQLite database. The PostgreSQL configuration resets the dedicated `stitching_test` database: never target a real business database. Docker creates it on first initialization; older volumes may need `docker compose exec postgres createdb -U stitching stitching_test`.

`composer test` runs PHP formatting, PHPStan level 7 (1 GiB analysis memory limit), and the functional/unit suite. These checks passed in the included verification run.

Browser workflow source is in tests/browser/workflow.spec.ts. It requires Playwright Chromium, the isolated fixture generated by scripts/qa/seed-browser.php, and a server using that same browser database. That fixture requires APP_ENV=testing and a database name containing `browser`; run the server with APP_ENV=local to retain real CSRF checks. Do not use the fixture on your business database.
